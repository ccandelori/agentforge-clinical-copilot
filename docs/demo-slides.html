Context

The clinician's problem

Open a patient chart. You have 3 minutes before the next appointment. You need to know:

  • What's this patient's active problem list?
  • What are they currently on?
  • Anything notable since their last visit?

Today: 5+ clicks across 3 tabs. Goal: ask in natural language, get a grounded answer with citations — without leaving the chart.

Design choice 1 of 3

Why a sidecar, not "agent code in PHP"

OpenEMR is a 20-year-old PHP codebase

Strict typing now (PHPStan level 10), but heavy legacy surface. Async LLM client work doesn't belong in Apache request lifecycles.

Python is where the AI ecosystem lives

Pydantic, Anthropic SDK, LangGraph, ruff, mypy. Better to embrace it as a separate process than try to drag it into the PHP stack.

PHP's only job is session → JWT → proxy. Everything agent-shaped is in the sidecar. Clean process boundary, clean dependency boundary.
5 / 9
Design choice 2 of 3

The JWT travels in both directions

Most agent demos talk to a database directly. We don't.

  • Every patient-data read goes back through OpenEMR's PHP layer via internal endpoints
  • The sidecar forwards the same user-bound JWT it received from the browser
  • The PHP internal endpoint refuses any request whose JWT patient_id claim doesn't match the requested pid
  • Every read still hits OpenEMR's existing audit-log machinery — we inherit AUDIT.md compliance for free
We could have read MariaDB directly from Python. We chose the more expensive path because the audit chain only works if every read flows through PHP.
6 / 9
Design choice 3 of 3

The LLM never chooses which patient to look at

Each tool spec offered to Claude has zero LLM-visible parameters:

MEDICATIONS_TOOL_SPEC = ToolSpec(
    name="get_active_medications",
    description="Look up the active patient's currently active medications. ...",
    input_schema={
        "type": "object",
        "properties": {},   // no inputs
        "required": [],
    },
)

Patient_id is bound at the RequestContext layer from the JWT, not from anything Claude says.

The model decides whether to call a tool. Never who about. A jailbreak that says "look up Bob in chart 5" can't actually do anything.
